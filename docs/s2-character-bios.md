# S2 角色介绍

256 位角色的中文简介保存在 `seasons/s2/character-bios.json`，按角色 ID、游戏、名称三重对应到已确认的素材名单。每位角色一段约 30–75 字的编辑简介，聚焦身份、性格及故事起点，不作为完整剧情档案或皮肤发布时间声明。

资料截至 2026-11-04。优先参考游戏角色档案；社区资料使用 BWIKI、异环信息站等，并为每条保留具体来源链接。部分来源为社区整理，并非逐条获得官方背书。介绍采用改写，避免照搬长篇档案。异环薄荷的一个社区页面误用了早雾故事，已改用异环信息站核对；明音凛的乐队名以角色资料中的「猫头音！！！！」为准。锁暝采用官方「十重契」角色档案。

## 展示与赛季隔离

- S2 卡片展示 `summary`，不再优先展示素材文件名或皮肤备注。
- 详情展示同一份赛季快照简介，角色资料参考链接与素材来源分开。
- 引用链接仅在 ID、游戏、名称及简介全文都匹配时出现，防止把当前资料链接冒充旧快照的来源；不会在前端覆盖历史简介。
- 预览准备脚本在草稿导入时写入简介，正式离线发布计划同步包含简介及出处。缺少对应介绍时直接报错。
- 本次本地预览重建于全新的 `/tmp/fumoe-s2-preview-*` 目录，再运行既有进行中演示脚本；旧目录保留，不绕过已开赛素材冻结触发器，不写生产数据库。
- S1 原始介绍、历史素材及赛果保持原有版本。正式赛季开赛日期仍未确定。

## 验证

目录覆盖检查验证 256 个身份、无重复 ID、无文件名或占位说明、有效 HTTPS 出处；另验证跨游戏同名角色及历史快照来源隔离。浏览器回归检查 S2 图鉴卡片展示简介而不是服装名，详情仍单独提供服装信息。
