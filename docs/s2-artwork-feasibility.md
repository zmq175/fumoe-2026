# S2 素材与对局卡实施方案

本轮处理全部 256 位角色，包含此前补齐的 21 位与已有来源的角色。全量 256 人的最新服装核验与既有素材精修单独计数，不能用「原图已找到」替代「处理完成」。不修改 S1、生产数据库或开赛状态。

## 一份来源，三套构图

- 身份键为游戏 + 角色 ID。来源原图只追加、不覆盖；保存来源页面、文件 URL、SHA-256、服装名、检索截止日及处理方式。
- 立绘画布 900×1200，透明底，人物可见剪影高最多 1080，底线 y=1140；宽姿态按宽度收缩，不能横向拉伸。只有半身官方素材时保留半身，不用生成模型补造腿部。
- 对局画布 960×540，眼线 y≈205（38%），脸宽约 170；逐角色保存眼睛中心与脸宽，以人物面部而非特效框计算缩放。移动端额外导出 540×540，眼线和脸宽按窄屏重新定位，不直接裁掉桌面图。
- 小头像以旧版 public/portraits/*.png 为样式基准：512×512 透明 PNG，460×460 内容区，四边各 26 px 留白，按用户确认的积分榜截图制作证件照式胸像：头、肩膀及少量胸口，不保留到腰部。与旧版一样 contain、底部对齐。内容区默认脸宽约 170 px、眼线 y=210；按角色头饰和姿态独立微调，不按武器或特效包围框缩小脸部，并在积分榜 58×70、淘汰赛 42×44、历史 42×48 下复核。来源保持与所选服装一致，S1 文件不覆盖。
- 原图已透明、主体独立时仅做确定性布局导出。复杂场景和白底经 GPT Image 提取背景；AI 结果保存为衍生图，不标成官方原图。核对五官、发型、服装、饰品、武器、边缘；保留 AI 处理说明。

## 对局卡落地

左右独立透明人像叠在同色深底，脸大小和眼线一致。头饰尽量完整，身体下部及远端武器允许裁切；不镜像角色，避免左右服装细节颠倒。姓名、游戏、卫冕标识在图外。移除素材内的验证文字与装饰水印。

组件只读取该赛季已锁定的素材版本。开赛前可更换并重新导出；开赛后冻结 manifest 哈希。历史卡继续读取 S1 素材引用。比赛状态由真实状态决定，历史已结束比赛不显示待开赛或倒计时；状态修复属于后续 UI 工作，不在素材补齐时修改历史记录。

## 验收

原图存在且可解码、身份有来源；导出图尺寸固定且存在实际透明像素；眼线/脸宽按已记录坐标定位；头像与立绘同源。桌面双人卡和手机窄屏检查，无截脸、无拉伸、无背景文字、无 Q 版。低清原图及 AI 细节不确定项单独展示，不能自动升级为正式素材。

正式上线仍需全量素材复核及项目规定的合并检查和明确上线授权。此次只提供隔离预览。

## 胸像返工门槛

用户否决白芷、坎特蕾拉、洛可可、李素裳的带道具裁切。胸像须是人物自身轮廓，不能保留人物后方的伞面、召唤物、场景或方形插画。技术检查通过不代表视觉合格。已否决图以 avatarReview.status=rejected 撤下，列表、详情与已导出筛选统一屏蔽；返工通过后才重新展示。小头像专用 portraitArtwork 优先于全身图自动裁切，不覆盖完整立绘或 S1。
