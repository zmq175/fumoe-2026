# 对局横图构图

保持既有 16:9 对局框、3:4 图鉴和 1:1 头像比例，不改变黑青科技风。首页主宣传语不绑定人数，实际人数与分组在赛季说明行中动态展示。

旧离线素材处理器统一从顶部取横图，部分角色的脸因此落到画面底边。已被裁掉的部分无法通过 CSS 恢复，应在素材工作台用原始立绘重新裁切，而不是拉伸横图。

工作台默认进入对局横图，参考线只显示在预览上，不写入导出文件。建议眼睛靠近画面高度 42% 的横线、脸部靠近中轴、脸宽约占 1/4；不同姿态允许合理偏差。透明区域沿用深色底，不强行去除原图背景。

每种比例独立调整。原图未替换时，未编辑的比例直接保留已发布图片的字节，不重新裁切；读取失败即停止发布。更换原图则需检查三种比例。裁切区域额外保存原图百分比，便于不同设备重新打开时恢复构图；旧 x/y/zoom/rotation 格式仍兼容。

每次发布创建独立媒体版本，仅未完成赛季跟随更新，已结束／归档赛季仍引用原版本。操作会写审计记录，原始静态素材不覆盖。

本次只对本地预览的鉴心、长离、青衣、艾莲四位进行了人工示例校准，不代表全部 128 位角色已完成逐图校准。`scripts/preview-match-framing.mjs --apply-local` 可通过 8788 本地素材接口重现；禁止用于生产。未来其他角色通过同一工作台逐图检查，不能把本次四个裁切参数通用于其他角色。

相关实现：`src/components/ArtworkEditor.tsx`、`src/components/artwork-crop.ts`、`src/components/artwork-framing.css`。浏览器测试覆盖文案动态人数、构图恢复、仅调整横图时其他比例字节不变。
