# 全站展示图片再次有损压缩

用户允许降低位图质量以减少体积。沿用已有 `images:compress` 流程，从原文件而非旧压缩结果编码：

- 头像 WebP Q75；详情图 Q78；其他位图 Q70。
- 透明通道 alphaQuality=100；保留现有尺寸策略（头像最多 192×192，详情最多 1280×1920，其余不缩放）。
- 新候选仅在小于已有展示文件时采用。公司和游戏 LOGO 继续使用独立映射，沿用上一轮挑选的较小版本；SVG 保持矢量。
- 从生产公开接口读取所有赛季素材地址，原文件哈希必须匹配对应版本。
- 新文件采用内容寻址及一年 immutable 缓存；保留旧展示资源、历史归档和数据库记录。
- 保留未被本次清单覆盖的已有映射，避免名单变化导致历史展示退回大图。

运行：`NODE_USE_ENV_PROXY=1 npm run images:compress`。明细输出在 `.local/image-compression/report.json`。

## 本轮结果

扫描 2358 个来源地址，按原文件去重为 1839 份素材。原图总计 360393697 字节；本轮处理前展示总计 147806418 字节，处理后 129076406 字节，减少约 12.7%。这是素材库汇总，不是单页下载量。

单独核对已有展示映射：未丢失任何旧映射，所有新目标文件均不大于旧目标；已有映射对应体积合计从 147624554 降为 128898836 字节，减少约 12.7%。本轮扫描也覆盖了原先没有压缩映射的素材，因此两种统计口径不同。

旧资源保留以兼容已有缓存与回滚，仓库／部署资源总占用会增加，但客户端只请求映射后的较小版本。

验证：1830 对更新前后展示图逐一确认尺寸及透明通道完全一致；153 项测试、40 项浏览器测试、类型检查及构建通过。已抽查头像、对局、图鉴、移动展示、详情与图形的新旧对照。
