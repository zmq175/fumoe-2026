# 赛季配置局部 UI 约定

遵循用户确认的 [整体视觉风格约束](visual-style-contract.md)：优化设计，不更换整体风格。

方向为 Operate，沿用既有后台的纸白底、黑字和青色主操作。颜色以 `src/styles.css` 的 `--paper`、`--ink`、`--cyan` 为准；此文仅约束赛季配置扩展。

规则、晋级与默认排期先展示，阵营、名单导入、逐轮日历使用原生折叠区。桌面字段双列，640px 以下单列；后台整体在 720px 以下单列。tab 与排期表局部横滚，避免撑宽页面；手机显示横滑提示。字段间距 16px，输入框采用白底、描边与 4px 圆角。

操作顺序为规则配置 → 显式保存 → 名单导入 → 模拟 → 独立发布。保存不会发布；模拟使用已保存数据，以种子决定胜负且不影响真实比赛。配置、名单或日历有未保存修改时，禁止模拟和发布，并显示文字原因。处理期间禁用相关控件；失败用错误提示，成功用状态反馈。已发布规则冻结，只有符合状态要求且尚未开始的轮次可调整时间。

保留字段标签、fieldset/legend、表头作用域和轮次输入的可访问名称。横滚表区域可获键盘焦点；输入、折叠标题及表区域保留可见焦点。加载与反馈使用 status，错误使用 alert；状态不能只靠颜色表达。常规输入及折叠标题保留至少 44px 高度。

行为源为 `src/components/SeasonConfiguration.tsx`，局部样式为 `src/components/season-configuration.css`，发布禁用与执行前检查接入 `src/main.tsx`。维护时同步未保存状态与发布门禁，不复制全局 token。此次记录不改根 DESIGN、sidecar，也不补建 PRODUCT；修复验收不代表全站视觉或可访问性认证。
