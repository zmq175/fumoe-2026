- 256 位角色，8 个游戏；按游戏＋角色名与唯一 ID 校验，人数与用户名单一致。
- 1,280 张展示图，约 270.1 MiB；逐文件记录 SHA-256、尺寸、格式、透明通道以及正式对象路径模板。
- 路径使用实际文件内容哈希，与演示环境的对象路径独立。正式 seasonId 尚未填入。
- 原画归档另记录内容校验值。丽芙、露娜、曲为用户提供，保留明确归属，不复用已被替换的旧候选网址。
- 名称暂拟“府萌 S2”，日期及抽签种子为空；文件明确 `readyToPublish:false`。

这是一份导入准备计划，不是可直接执行的上传包。正式导入还需沿用后台接口要求的原画／来源字段；三张用户提供图须按真实来源补齐导入归属，不得伪造公开来源 URL。
