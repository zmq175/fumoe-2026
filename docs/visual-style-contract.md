# 视觉风格约束（用户确认）

用户明确要求：首页科技风网格背景必须保留，后续页面和功能延续现有整体风格；允许优化设计，不允许借优化更换视觉体系。

## 保留的视觉身份

- 首页科技感网格背景，以及现有黑色、青色主视觉。
- 内容与后台的纸白底、黑字，与深色赛事区域的既有搭配。
- 现有品牌标识、字体分工、强调线条和赛事／阵营识别方式。
- 新功能优先复用现有 token、控件和构图语言，不自行引入另一套主题。

## 可以优化

- 信息层级、留白、对齐、密度与文字可读性。
- 手机适配、滚动、触控、键盘操作与无障碍体验。
- 表单流程、反馈、错误提示及性能。

优化须保留整体风格；涉及移除首页网格、替换主色／字体体系、重做品牌或整体视觉方向时，先取得用户明确同意。机械检测器的风格偏好不能覆盖这项用户约束。

样式实现以 `src/styles.css` 为当前依据，局部后台约定见 [赛季配置 UI](season-configuration-ui.md)。本文件是确认后的设计约束，不是全站质量认证。
