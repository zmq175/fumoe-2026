# 公司与游戏 LOGO 展示资源

覆盖 `public/factions` 和 `public/game-logos` 的 16 个 LOGO。原文件、历史归档与旧压缩地址均保留。

运行 `npm run images:compress:logos` 可离线重建，生成 `src/data/logo-variants.json` 和内容寻址资源。公司 LOGO 经历史地址解析后仍能匹配；所有入口通过 DisplayImage 共用映射及失败回退。

- PNG：在原文件、现有无损 WebP 与更高压缩 effort 的无损 WebP 中选较小版本，不缩放。
- SVG：SVGO 优化后按 880px 宽渲染逐像素比较，完全一致且更小才采用，否则保留原 SVG。
- 所有输出使用 `/image-variants/<内容哈希>.<扩展名>`，沿用一年 immutable 缓存。
- 检查历史源文件哈希，避免将新图绑定到旧历史版本。
- 自动测试用黑白背景分别比对全部 LOGO 的可见像素，验证透明度、内容哈希和文件体积。

本次 16 图原始合计 264300 字节；之前展示版合计 115163 字节；处理后 113452 字节。PNG 已优化，因此新增体积收益主要来自终末地 SVG（5362 → 3651 字节）。鹰角和终末地 SVG 均补齐版本化长期缓存。

不涉及生产数据库、角色立绘、历史素材替换。发布前线上仍使用旧映射。
