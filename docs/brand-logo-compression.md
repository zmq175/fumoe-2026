# 公司与游戏 LOGO 展示资源

覆盖 `public/factions` 和 `public/game-logos` 的 16 个 LOGO。原文件、历史归档与旧压缩地址均保留。

运行 `npm run images:compress:logos` 可离线重建，生成 `src/data/logo-variants.json` 和内容寻址资源。公司 LOGO 经历史地址解析后仍能匹配；所有入口通过 DisplayImage 共用映射及失败回退。

- PNG：比较原文件、已有无损 WebP、高 effort 无损 WebP 与 Q80 有损 WebP；有损额外节省至少 5% 才采用。保持原分辨率，alphaQuality=100 保留精确透明度。
- SVG：SVGO 优化后按 880px 宽渲染逐像素比较，完全一致且更小才采用，否则保留原 SVG。
- 所有输出使用 `/image-variants/<内容哈希>.<扩展名>`，沿用一年 immutable 缓存。
- 检查历史源文件哈希，避免将新图绑定到旧历史版本。
- 自动测试验证尺寸、透明通道、内容哈希和文件体积；SVG 可见像素须完全一致，位图在黑白背景下平均通道误差须小于 5/255。另检查有损版本的原图对照图。

本次 16 图原始合计 264300 字节；之前展示版合计 115163 字节；无损方案合计 113452 字节；用户允许有损后合计 99424 字节，再节省约 12.4%。采用有损的 4 张为蛮啾、NEXON、星穹铁道、异环，其余保留更小的无损版本。终末地 SVG 从 5362 降到 3651 字节。鹰角和终末地 SVG 均补齐版本化长期缓存。

不涉及生产数据库、角色立绘、历史素材替换。发布前线上仍使用旧映射。
